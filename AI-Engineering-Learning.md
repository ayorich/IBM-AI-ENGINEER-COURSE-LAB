## 📖 **AI Industry Terminology & Glossary**

### **Machine Learning Fundamentals**

- **Supervised Learning**: Learning from labeled data (input-output pairs)
- **Unsupervised Learning**: Finding patterns in data without labels
- **Semi-supervised Learning**: Learning from a mix of labeled and unlabeled data
- **Reinforcement Learning (RL)**: Learning through interaction with an environment, receiving rewards/penalties
- **Transfer Learning**: Using a pre-trained model on a new, related task
- **Fine-tuning**: Adjusting a pre-trained model's weights for a specific task
- **Feature Engineering**: Creating or selecting relevant input variables
- **Hyperparameter**: Configuration settings that control the learning process (not learned from data)
- **Overfitting**: Model performs well on training data but poorly on new data
- **Underfitting**: Model is too simple to capture patterns in the data
- **Bias-Variance Tradeoff**: Balance between model complexity and generalization
- **Cross-validation**: Technique to assess model performance by splitting data into multiple folds
- **Regularization**: Techniques to prevent overfitting (L1/L2, dropout, etc.)
- **Ensemble Learning**: Combining multiple models to improve performance
- **Gradient Descent**: Optimization algorithm to minimize loss function
- **Backpropagation**: Algorithm for training neural networks by propagating errors backward

### **Deep Learning & Neural Networks**

- **Neural Network**: Computing system inspired by biological neural networks
- **Perceptron**: Simplest type of neural network (single neuron)
- **Multi-layer Perceptron (MLP)**: Neural network with multiple layers
- **Activation Function**: Function that introduces non-linearity (ReLU, Sigmoid, Tanh)
- **Loss Function**: Measures how far model predictions are from actual values
- **Optimizer**: Algorithm that updates model weights (SGD, Adam, AdamW)
- **Learning Rate**: Step size in gradient descent optimization
- **Batch Size**: Number of training examples used in one iteration
- **Epoch**: One complete pass through the entire training dataset
- **Vanishing Gradient Problem**: Gradients become too small to update early layers
- **Exploding Gradient Problem**: Gradients become too large, causing instability
- **Dropout**: Regularization technique that randomly sets neurons to zero during training
- **Batch Normalization**: Normalizing layer inputs to stabilize training
- **Layer Normalization**: Normalizing across features instead of batch dimension
- **Weight Initialization**: Strategy for setting initial weights in neural networks
- **Gradient Clipping**: Limiting gradient values to prevent exploding gradients

### **Convolutional Neural Networks (CNNs)**

- **Convolution**: Mathematical operation that applies filters to extract features
- **Kernel/Filter**: Small matrix used in convolution operations
- **Pooling**: Downsampling operation (Max Pooling, Average Pooling)
- **Stride**: Step size of the filter during convolution
- **Padding**: Adding zeros around input to control output size
- **Feature Map**: Output of applying a filter to an input
- **Receptive Field**: Region of input that affects a particular neuron
- **Transfer Learning**: Using pre-trained CNN models (VGG, ResNet, etc.)
- **Data Augmentation**: Creating variations of training data (rotation, flipping, etc.)

### **Recurrent Neural Networks (RNNs)**

- **RNN**: Neural network designed for sequential data
- **LSTM (Long Short-Term Memory)**: RNN variant that can learn long-term dependencies
- **GRU (Gated Recurrent Unit)**: Simplified LSTM variant
- **Bidirectional RNN**: Processes sequence in both forward and backward directions
- **Sequence-to-Sequence (Seq2Seq)**: Model that maps sequences to sequences
- **Attention Mechanism**: Allows model to focus on relevant parts of input
- **Encoder-Decoder**: Architecture with encoder (input) and decoder (output)

### **Transformers & Large Language Models**

- **Transformer**: Architecture based on self-attention mechanism
- **Self-Attention**: Mechanism allowing model to attend to different positions in sequence
- **Multi-Head Attention**: Multiple attention mechanisms in parallel
- **Positional Encoding**: Information about token positions in sequence
- **Tokenization**: Breaking text into smaller units (tokens)
- **Embedding**: Dense vector representation of tokens/words
- **Pre-training**: Training model on large unlabeled dataset
- **Fine-tuning**: Adapting pre-trained model to specific task
- **Prompt Engineering**: Crafting inputs to get desired outputs from LLMs
- **Few-shot Learning**: Learning from few examples in the prompt
- **Zero-shot Learning**: Performing task without training examples
- **Chain-of-Thought (CoT)**: Reasoning process shown in prompts
- **Hallucination**: Model generating factually incorrect information
- **Temperature**: Parameter controlling randomness in text generation
- **Top-k Sampling**: Sampling from k most likely next tokens
- **Top-p (Nucleus) Sampling**: Sampling from tokens with cumulative probability p

### **LLM Fine-tuning & Optimization**

- **LoRA (Low-Rank Adaptation)**: Efficient fine-tuning using low-rank matrices
- **QLoRA**: Quantized LoRA for memory-efficient fine-tuning
- **PEFT (Parameter-Efficient Fine-Tuning)**: Methods to fine-tune with fewer parameters
- **Instruction Tuning**: Fine-tuning on instruction-following tasks
- **RLHF (Reinforcement Learning from Human Feedback)**: Training with human preferences
- **Quantization**: Reducing model precision (FP32 → FP16 → INT8)
- **Pruning**: Removing unnecessary weights/neurons
- **Knowledge Distillation**: Training smaller model to mimic larger model
- **Model Compression**: Techniques to reduce model size and inference time

### **Retrieval-Augmented Generation (RAG)**

- **RAG**: Combining retrieval and generation for better LLM responses
- **Vector Database**: Database optimized for similarity search
- **Embedding**: Dense vector representation of text
- **Semantic Search**: Finding relevant content based on meaning
- **Chunking**: Breaking documents into smaller pieces
- **Retrieval**: Finding relevant documents/context
- **Context Window**: Maximum tokens model can process
- **Dense Retrieval**: Using embeddings for retrieval
- **Sparse Retrieval**: Using keyword-based retrieval (BM25, TF-IDF)

### **Generative AI**

- **GAN (Generative Adversarial Network)**: Generator vs Discriminator architecture
- **VAE (Variational Autoencoder)**: Probabilistic encoder-decoder model
- **Diffusion Model**: Generative model that adds/removes noise iteratively
- **DDPM (Denoising Diffusion Probabilistic Model)**: Type of diffusion model
- **Stable Diffusion**: Popular open-source diffusion model
- **Latent Space**: Compressed representation of data
- **Mode Collapse**: GAN problem where generator produces limited variety
- **FID (Fréchet Inception Distance)**: Metric for evaluating generative models

### **Computer Vision**

- **Object Detection**: Locating and classifying objects in images
- **Semantic Segmentation**: Classifying each pixel in an image
- **Instance Segmentation**: Detecting and segmenting individual object instances
- **YOLO (You Only Look Once)**: Fast object detection algorithm
- **R-CNN**: Region-based CNN for object detection
- **U-Net**: Architecture for image segmentation
- **Image Classification**: Categorizing entire images
- **Transfer Learning**: Using pre-trained vision models
- **Data Augmentation**: Creating variations of images for training
- **Bounding Box**: Rectangle around detected object
- **IoU (Intersection over Union)**: Metric for object detection accuracy
- **mAP (mean Average Precision)**: Evaluation metric for object detection

### **Reinforcement Learning**

- **Agent**: Entity that makes decisions in RL
- **Environment**: World in which agent operates
- **State**: Current situation of the environment
- **Action**: Decision made by agent
- **Reward**: Feedback signal from environment
- **Policy**: Strategy for selecting actions
- **Value Function**: Expected future rewards
- **Q-Learning**: Value-based RL algorithm
- **DQN (Deep Q-Network)**: Q-Learning with neural networks
- **Policy Gradient**: Directly optimizing policy
- **PPO (Proximal Policy Optimization)**: Popular policy gradient method
- **Actor-Critic**: Combining value and policy methods
- **Exploration vs Exploitation**: Balance between trying new actions and using known good ones
- **Reward Shaping**: Designing reward function to guide learning

### **Model Training & Optimization**

- **Training**: Process of learning from data
- **Inference**: Using trained model to make predictions
- **Forward Pass**: Computing predictions from input
- **Backward Pass**: Computing gradients for training
- **Gradient**: Derivative of loss with respect to parameters
- **Learning Rate Schedule**: Adjusting learning rate during training
- **Warmup**: Gradually increasing learning rate at start
- **Early Stopping**: Stopping training when validation performance plateaus
- **Checkpointing**: Saving model state during training
- **Mixed Precision Training**: Using FP16 and FP32 for faster training
- **Distributed Training**: Training across multiple GPUs/machines
- **Data Parallelism**: Splitting data across devices
- **Model Parallelism**: Splitting model across devices
- **Gradient Accumulation**: Accumulating gradients over multiple batches

### **Model Evaluation & Metrics**

- **Accuracy**: Percentage of correct predictions
- **Precision**: True positives / (True positives + False positives)
- **Recall**: True positives / (True positives + False negatives)
- **F1 Score**: Harmonic mean of precision and recall
- **Confusion Matrix**: Table showing prediction vs actual results
- **ROC Curve**: Receiver Operating Characteristic curve
- **AUC**: Area Under the ROC Curve
- **MSE (Mean Squared Error)**: Average squared difference
- **MAE (Mean Absolute Error)**: Average absolute difference
- **R² (R-squared)**: Coefficient of determination
- **BLEU Score**: Metric for text generation quality
- **Perplexity**: Measure of how well model predicts text
